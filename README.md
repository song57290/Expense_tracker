# 접속 사이트
```
https://expense-tracker-ajeegq.fly.dev/   ← 배포 주소 (PC 꺼도 작동)
http://127.0.0.1:5000/                    ← 로컬 개발용
```

# 배포 (코드 수정 후 반영)

VS Code에서 코드 수정 후 `deploy.bat` 더블클릭 — 끝.

또는 터미널에서:
```
cd C:\Users\song5\Expense_tracker
fly deploy --ha=false
```

# 구현된 기능

| 파일 | 내용 |
| :-----: | :-----: |
| models.py | Transaction / Budget / Category / Card 테이블 |
| app.py | 내역 CRUD, 카드 관리, 카테고리 관리, 통계, 예산, 가져오기, 푸시 알림 |
| index.html | 요약·카드실적·카테고리지출·내역추가·내역목록 (섹션 토글) |
| budget.html | 카드별 잔고 자동계산 (초기잔고+수입-지출) + 스와이프 수정/삭제 |
| stats.html | 도넛·막대 차트, 카드별 지출, 카테고리 범례 |
| calendar.html | 월별 캘린더, 날짜 클릭 상세, 내역 추가/수정 |
| categories.html | 지출/수입 탭 분리, 드래그 순서 변경 |
| cards.html | 카드 등록·수정·삭제, 실적 구간 설정 |
| static/sw.js | 서비스 워커 (PWA + 푸시 알림 수신) |
| static/push.js | 알림 구독/해제 UI 로직 |
